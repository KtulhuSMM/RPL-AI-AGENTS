# RPL AI Agent — продуктовые вопросы и решения

Этот файл — рабочий бриф проекта. Он нужен, чтобы до реализации спорной функции сначала принять продуктовое решение, а затем дать Codex однозначное требование.

## Как использовать

Для каждого вопроса отмечаем один вариант или вписываем свой ответ. После принятия решения меняем статус `Нужно решить` на `Решено` и при необходимости переносим требование в `SPECIFICATION.md`. Codex не должен самостоятельно придумывать ответ на вопрос со статусом `Нужно решить`, если от него существенно зависит UX, данные, ML или стоимость продукта.
